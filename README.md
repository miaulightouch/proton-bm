# Proton-BM

Bemani-focused improvements to [Proton-CachyOS](https://github.com/CachyOS/proton-cachyos).

- **Multitouch:** Windows pointer input on XWayland and Wayland.
- **Sound System:** PipeWire exclusive audio, DirectSound effects and audio device fixes.
- **Media Playback:** WMA/WMV playback compatibility and DirectShow video fixes.
- **Shader Compatibility:** Shader Model 2 `sincos` compilation.

See the [wiki](https://github.com/miaulightouch/proton-bm/wiki) for supported behavior, limitations and setup, including [dsdmo.dll](https://github.com/miaulightouch/proton-bm/wiki/dsdmo.dll).

For building, see the [upstream guide](https://github.com/CachyOS/proton-cachyos/blob/cachyos_main/BUILDING.md).
